Welcome to My WebAPI Repo!

This repository contains a Poll Management System built with ASP.NET Core Web API. It allows administrators and users to manage polls, 
add questions, submit votes, and view results smoothly.

---
Try It Out
You can test and explore the live API documentation directly here:
https://web1-api.runasp.net/
